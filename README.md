ケアすてっぷ
― 妊娠・出産に伴う社内手続きをサポートするアプリ

## 1. サービス概要

「ケアすてっぷ」は、妊娠・出産に伴う社内手続きを行う労務担当者を支援するアプリです。
妊娠・出産に伴う手続きでは、社員ごとに必要な手続きや期限が異なり、複数の社員を担当する場合には、それぞれの進捗を把握する必要があります。
現在の業務では、手続き書類を紙でキャビネットに保管しており、進捗を確認する際には対象社員の書類を探して確認しています。
ケアすてっぷでは、社員ごとの手続き・期限・進捗を画面上で一元管理することで、書類を探すことなく現在の状況を把握し、次に対応すべき手続きを判断しやすくすることを目指します。
※卒業制作のMVPでは、労務担当者側の機能に対象を絞って開発します。

## 2. アイデアのきっかけ

労務担当者として妊娠・出産に伴う手続きを行う中で、手続き書類を紙で管理しているため、進捗を確認する際に対象社員の書類を探す必要があることに課題を感じました。
書類を確認すれば、どの手続きが完了しているか、まだ完了していないかを把握できますが、書類が他の書類に紛れてしまい、必要な書類を探すのに時間がかかることがあります。
そこで、社員ごとの手続き・期限・進捗を画面上で確認できるようにすることで、労務担当者の確認・管理業務を効率化できるのではないかと考え、「ケアすてっぷ」を企画しました。

## 3. 解決したい課題

### 労務担当者が社員ごとの手続き状況を確認するために、紙の書類を探す必要がある

妊娠・出産に伴う手続きでは、社員ごとに複数の手続きを管理する必要があります。
現在は手続き書類を紙でキャビネットに保管しているため、進捗を確認する際には対象社員の書類を探して確認しています。
この方法でも手続き状況を確認することはできますが、必要な書類を探す手間があり、複数の社員を担当する場合には確認・管理の負担が大きくなります。
ケアすてっぷでは、社員ごとの手続き・期限・進捗を一元管理することで、書類を探すことなく現在の状況を確認できるようにします。

## 4. ターゲットユーザー

### メインターゲット

妊娠・出産に伴う社内手続きを担当する労務担当者

### MVPで想定する利用者

卒業制作のMVPでは、労務担当者のみを利用者としています。
社員側のログイン・操作機能はMVPでは実装せず、労務担当者が社員情報や手続き状況を登録・確認・更新することに対象を絞ります。

### 利用イメージ

1. 労務担当者が社員を登録する
2. 出産予定日などの社員情報を登録する
3. 社員ごとの手続き・期限を登録する
4. 手続きの進捗を「未着手・対応中・完了」で管理する
5. 手続きの進行に応じて労務担当者が進捗を更新する
6. ダッシュボードで社員ごとの最新の手続き状況を確認する

### MVPで検証したいこと

労務担当者が社員ごとの手続き・期限・進捗を一か所で確認できることで、紙の書類を探すことなく現在の状況を把握し、次に対応すべき手続きを判断しやすくなるかを検証します。

### MVPの検証方法

卒業制作時点では、実際の社員情報は使用せず、架空の社員情報を登録して検証します。
また、私だけではなく、労務チームのメンバーにも検証に協力してもらうことを想定しています。
一般的な妊娠・出産に伴う手続きを対象とし、特殊なケースはMVPの対象外とします。
現在の業務では、手続き書類を紙でキャビネットに保管し、手続きの進捗を確認する際には対象社員の書類を探しています。
MVPでは、これをケアすてっぷ上で再現し、社員ごとの手続き・期限・進捗を一元管理することで、以下を確認します。

- 社員ごとの現在の手続き状況をすぐに確認できるか
- 次に対応すべき手続きを判断しやすくなるか
- 紙の書類を探して確認する手間を減らせるか

## 5. 競合・差別化

妊娠・出産に伴う手続きについては、freeeやSmartHRなどの人事労務サービスでも関連する機能が提供されています。
一方で、これらは給与計算や勤怠管理、社会保険手続きなど、人事・労務業務全体を幅広く支援するサービスです。
ケアすてっぷでは、妊娠・出産に伴う社内手続きに対象を絞り、労務担当者が社員ごとの手続き・期限・進捗を一元的に確認できることを目指します。
既存の人事労務システムを置き換えるのではなく、妊娠・出産に伴う手続き管理を補完するサービスとしての利用を想定しています。

## 6. 提供する価値

### 労務担当者が手続き状況を把握しやすくなる

ケアすてっぷでは、社員ごとの手続き・期限・進捗を一か所で確認できるようにすることで、紙の書類を探すことなく現在の状況を把握できるようにします。
これにより、労務担当者が社員ごとの手続き状況を確認し、次に対応すべき手続きを判断しやすくすることを目指します。

## 8. 懸念点と対応策

### 手続きの複雑さ

妊娠・出産に伴う手続きには、出産日や多胎などによって対応が変わるケースがあります。
MVPでは一般的な妊娠・出産に伴う手続きに対象を絞り、複雑なケースは対象外とします。

### 法令・行政手続きの変更

妊娠・出産に関する制度や行政手続きは、法改正などによって変更される可能性があります。
MVPでは対象となる一般的な手続きに絞って実装し、法改正や様式変更が発生した場合は、労務担当者が登録する手続き情報を更新できる仕組みを整えることを想定しています。

## 9. 今後の機能拡張

MVPで基本的な手続き管理の有用性を検証した上で、対象となる手続きや利用者を段階的に広げていくことを想定しています。
将来的には、社員自身が手続き状況を確認できる機能や、手続き期限の自動計算・通知、個別ケースへの対応などを追加し、妊娠・出産から育児休業・復職までを継続的に支援できるサービスを目指します。

### 技術選定理由

Ruby on Railsは、今回の卒業制作で必要となるデータ管理やCRUD処理を効率的に実装できることから採用しました。
React / Next.jsについても学習していますが、今回のMVPでは労務担当者向けの基本的な業務管理機能に対象を絞るため、Railsを中心に実装します。

### 技術面での課題

今回のMVPでは、社員情報、手続き情報、進捗情報など複数のデータを関連付けて管理する必要があります。
RailsのActive Recordやデータベース設計について理解を深めながら実装を進めます。
